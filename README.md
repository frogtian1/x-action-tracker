## 功能
- **每日目标**：七项各设一个当日目标（默认：点赞 20、回复 10、发帖 3、转发 5、曝光量 5000、关注 20、涨粉 10），悬浮窗实时显示「已完成 / 目标」和进度条，达标变绿打 ✓。涨粉一行还会显示当前总粉丝数。
- **自定义范围查看**：点「📅 历史查看」，自选起止日期，逐日看七项的完成数 / 目标 / 是否达标，并统计全部达标天数。
- **可拖动、可收起**：拖标题栏移动位置，点 – 收起。
- 数据只存在本机浏览器（chrome.storage.local），不上传；换一天自动从 0 开始计，历史保留在本机。v0.1.0 的旧数据可直接沿用。

## 安装 / 更新
1. 解压 zip（或直接用解压后的文件夹）。
2. Chrome 打开 `chrome://extensions`，开启右上角「开发者模式」。
3. 点「加载已解压的扩展程序」，选择本文件夹（从旧版更新：点旧扩展卡片上的刷新按钮，或移除后重新加载新文件夹）。
4. 打开或刷新 x.com，右下角出现悬浮窗。

## 计数口径（重要）
本插件不走 X API，是在本机按页面操作估算，方便自律打卡，不是官方精确统计：
- **点赞**：点亮爱心 +1，取消 −1（在装有插件的浏览器里操作才计）。
- **转发**：在转发菜单点「Repost/转帖」或确认转发 +1，取消转发 −1；引用转发不计。
- **发帖 / 回复**：点发帖按钮时，位于帖子详情页或回复弹窗内计「回复」，其余计「发帖」。
- **曝光量**：打开自己主页时，自动汇总**今天所发帖子**的浏览量（取当日观测到的最大值）；与官方后台口径可能有差异，可在「目标设置」里手动校正为后台数字。
- **关注**：点任意位置的「关注」按钮 +1，取关 −1（只计本浏览器里的操作；在主页/时间线/推荐位点的都算）。
- **涨粉**：打开自己主页时读取你的粉丝总数，减去**昨日最后一次记录的粉丝总数**，即为今日涨粉（掉粉显示负数）。第一天没有昨日基线，以当天首次读取为基线、当日涨粉从 0 起算；涨粉也可在设置里手动校正。

## 已知限制
- 在手机 App 或其他浏览器里的操作不会被计入。
- X 改版可能导致个别按钮识别失效；失效时对应项会少计，不会报错。
- 曝光量和涨粉都依赖你当天打开过自己主页；没打开时显示上次数值或手动值。
